# 🚦 GATIMARG KAVACH
### A Secure Edge Hardware & AI-Driven Electronic Design Automation (EDA) Framework for Smart City Traffic Infrastructure

> **IEEE CEDA Blitzkrieg 2026 – Electronic Design Automation (EDA) Challenge**  
> **Team:** Acyuta LABs

---

## 📖 Overview

**GATIMARG KAVACH** is a research-oriented cyber-physical framework designed to secure next-generation smart city transportation infrastructure through **Secure Edge Hardware**, **Hardware Root-of-Trust**, **Edge AI**, **Blockchain-backed Device Authentication**, and **Electronic Design Automation (EDA)** principles.

Unlike conventional cloud-centric cybersecurity solutions, GATIMARG KAVACH proposes a **hardware-first architecture** capable of authenticating edge IoT devices, detecting cyber threats locally, and providing a migration pathway from software prototypes to FPGA and ASIC implementations.

Developed as an entry for the **IEEE CEDA Blitzkrieg 2026 Hardware Hackathon**, the project focuses on building secure, intelligent, and trustworthy transportation infrastructure.

---

# 🎯 Problem Statement

Modern Intelligent Transportation Systems (ITS) rely on thousands of interconnected IoT devices, including:

- 🚦 Smart Traffic Signals
- 📹 CCTV Cameras
- 📡 Vehicle Detection Sensors
- 🌡 Environmental Sensors
- 💻 Edge Gateways

These connected infrastructures significantly expand the cyber-physical attack surface.

Common attack vectors include:

- Traffic Signal Manipulation
- Sensor Data Spoofing
- Rogue IoT Device Injection
- Identity Spoofing
- Commuter Privacy Leakage
- Cloud Latency during Threat Response

Current deployments primarily rely on centralized cloud security, lacking:

- Hardware Root-of-Trust
- Secure Edge Authentication
- Decentralized Device Identity
- Local Threat Isolation
